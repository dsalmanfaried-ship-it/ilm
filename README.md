# منصة العلم الشرعي — طريقة التشغيل والمشاركة

## الملفات
- `index.html` — التطبيق
- `data.js` — قائمة المشايخ والأقسام والفيديوهات

## التشغيل
افتح `index.html` في المتصفح. لازم يكون فيه إنترنت عشان مشغّل يوتيوب.

## إضافة فيديوهات
- من جوه التطبيق: زر "＋ إضافة" ← اختار الشيخ والقسم وحط رابط يوتيوب (فيديو أو playlist). بيتسجل على جهازك بس.
- عشان الكل يشوفها: من الرئيسية دوس "مشاركة محتوى القوائم"، انسخ النص، والصقه مكان محتوى `data.js`، وارفع الملفات تاني.

## المشاركة مع الناس (مجانًا)
1. ادخل على netlify.com/drop أو أنشئ مستودع GitHub وفعّل GitHub Pages.
2. اسحب مجلد المشروع كله (index.html + data.js).
3. هيطلع لك رابط ابعته لأي حد.

## تتبع المشاهدة
- بيتسجل الفيديو "مشاهَد" لما يخلص أو يوصل 90%، أو بالضغط على علامة ✓.
- التقدم محفوظ على جهاز كل شخص ومحدش بيشوف تقدم التاني.
- قوائم التشغيل (playlist) بتتعلّم يدويًا بعلامة ✓.
